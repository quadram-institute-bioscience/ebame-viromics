## Create your VM

> 🔑 Remember to [add your SSH key](https://corebio.info/ebame-viromics/modules/extras/keys/) to Biosphere before starting


#### What do we need?

Go to [BioSphere](https://biosphere.france-bioinformatique.fr/) and create a new VM with the following settings:


- UBUNTU 24.04 (**not** desktop)
- :warning: 32 Gb of RAM are needed, click on the :wrench: icon to select the appropriate flavor.

## Setting up your EBAME VM

We made a small script to help you set up your VM.

Execute it from the terminal:

```bash
# Execute a script to install dependencies and configure env
curl -sSL "https://raw.githubusercontent.com/quadram-institute-bioscience/ebame-viromics/refs/heads/gh-pages/setup.sh" > setup.sh

bash setup.sh
```



Finally:

```bash
# Make conda ready to work
conda init bash

# Apply modified settings
source ~/.bashrc
```

<details>
  <summary>What is this script doing?</summary>
  
  The script will check if you are on an EBAME VM and if you have enough resources.<br>
  Then will install some dependencies, and make a bookmark for the data directory (<code>$VIROME</code>), create links to datasets. <small><a href="https://github.com/quadram-institute-bioscience/ebame-viromics/refs/heads/gh-pages/setup.sh">See the source code</a></small>.

</details>
