---
title: Are you ready to start?
---

If you followed this introductory section, you should:

* Have a `$VIROME` variable set to the path of the data, so that you should see the input files if you:

```bash
ls -l $VIROME
```

* Have the databases inside the `$DB` bookmark.

```bash
ls -l $DB
```
You should see the two directories, one for genomad and one for checkv.

* Have `seqfu` running in your VM:

```bash
seqfu version
```

* Preferably, use [**tmux**] to keep the session safe from network glitches.
