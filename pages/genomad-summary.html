geNomad: virus summary

Final viral sequences in the human gut assembly.

Source: human_gut_assembly_virus_summary.tsv — 1,778 rows

What this shows. geNomad's final viral set from the human-gut assembly — the 1,778 sequences that passed the neural-network and hallmark-evidence checks, plus the 20 proviruses. Treat it as the clean virus list: rows whose topology is not No terminal repeats are proviral or have defined terminal repeats (DTR/ITR).

seq_name
Sequence identifier.
length
Sequence length in bp.
topology
Terminal-repeat structure: No terminal repeats (1,682), DTR (70), Provirus (20), ITR (6).
coordinates
Region on the source contig — set for proviruses, otherwise NA.
n_genes
Number of predicted genes.
genetic_code
Genetic code used for gene calling.
virus_score
Neural-network probability that the sequence is viral (max 0.9837 here).
fdr
False-discovery-rate value — NA for every row in this run.
n_hallmarks
Number of viral hallmark genes detected.
marker_enrichment
Enrichment of viral markers relative to cellular ones.
taxonomy
Assigned lineage (semicolon-separated ranks; blank tail ranks are empty).
