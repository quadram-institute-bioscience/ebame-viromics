How to search

Space between terms means and:
phage crAss → rows containing both.

-word excludes rows containing it.

"exact phrase" (with quotes) matches the whole string.

column:value searches one column only, e.g. host:pseudomonas (case-insensitive text match).

Shortcuts: / focus search · Esc clear.
